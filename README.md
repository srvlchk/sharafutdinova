# Вариант 22. Покрасочная камера

Курсовой проект по ПМ.02 «Сопровождение и схемотехническое обслуживание интеллектуальных интегрированных систем».
Разработка и сопровождение виртуальной системы сбора и учёта данных на Arduino.

## Входные данные

| Параметр | Значение |
|---|---|
| Сценарий | Покрасочная камера |
| Датчик 1 (аналоговый) | MQ2 — пары краски, 0–100 % (A0) |
| Датчик 2 | LDR — освещённость, 0–100 % (A1) |
| Датчик 3 | POT — давление воздуха, 0–10 бар (A2) |
| Исполнительное устройство | зуммер (D8) |
| Светодиод-индикатор | жёлтый, 10 мА, резистор 300 Ом (D7) |
| Период опроса T | 2 с |
| Порог события | пары краски > 35 % |

## Ссылка на проект Wokwi

https://wokwi.com/projects/479016090654074881

## Файлы

- `sim/diagram.json` — схема проекта Wokwi;
- `firmware/variant_22.ino` — скетч Arduino;
- `db/schema.sql` — создание таблиц readings и events; `db/queries.sql` — три контрольных запроса;
- `db/load.sql`, `db/variant.db` — создаются автоматически (в Git не входят);
- `nodered/flow.json` — поток Node-RED; `nodered/parse.js` — код функции разбора лога;
- `load_log.js` — запасной способ загрузки лога в базу без Node-RED (`node load_log.js`);
- `data/log.txt` — журнал штатного сценария; `data/log_fault.txt` — тест неисправности;
- `docs/` — рисунки, пояснительная записка и инструкция пользователя;
- `start-nodered.bat` — запуск Node-RED.

## Порядок запуска

1. Запустить `start-nodered.bat`, открыть http://127.0.0.1:1880, импортировать `nodered/flow.json`, нажать Deploy.
2. Запустить симуляцию в Wokwi, скопировать вывод Serial Monitor в `data/log.txt`, сохранить файл.
3. Проверить данные: `sqlite3 db\variant.db ".read db\queries.sql"`.
